Portainer Stack Generator

Creates the Compose YAML for the chatgpt-youtube-mcp stack: the read-only YouTube MCP server plus the OpenAI Secure MCP Tunnel.

Privacy

Everything on this page runs locally in your browser. The generated YAML and every value you enter exist only in this page's memory while it is open. The application performs no network requests after loading — nothing is uploaded, submitted, stored, or logged anywhere. When you are done, use Clear all sensitive data or simply close the tab.

The operating-system clipboard temporarily contains your secrets after you copy the YAML. Ordinary web JavaScript cannot securely erase physical memory or reliably clear every platform clipboard — paste into Portainer and clear your clipboard promptly.
